**Разработка стратегии взаимодействия с клиентами для фитнес-центра.**

**Цели проекта**

Спрогнозировать вероятность оттока (на уровне следующего месяца) для каждого клиента.
Формирование типичных портретов клиентов:
> - выделить несколько наиболее ярких групп и охарактеризовать их основные свойства
> -  проанализировать основные признаки, наиболее сильно влияющие на отток;
Cформулировать основные выводы и разработать рекомендации по повышению качества работы с клиентами:
> -   выделить целевые группы клиентов
> -   предложить меры по снижению оттока
> -   определить другие особенности взаимодействия с клиентами.

Ход исследования:

Мне нужно разобрать данные из CSV-файла: проверить их на ошибки, аномалии и соответствие типов данных. С помощью Seaborn сделаю анализ нагляднее — каждый график и важные моменты прокомментирую, чтобы сохранить логику исследования.

Библиотека scikit-learn поможет подобрать лучшую модель для прогноза оттока клиентов, а кластеризация — выделить основные группы клиентов. В конце подведу итоги и дам заказчику практические рекомендации — что улучшить и на что обратить внимание.
